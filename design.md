
# Student Card System - Design

## 1. Design Overview
A simple and attractive student ID card
dashboard.

## 2. Color Theme
- Blue: Header
- White: Student Card
- Light Grey: Background
- Green: Active Status

## 3. Card Layout
1. College card heading
2. Student status
3. Student profile photo
4. Student name
5. Roll number
6. Department
7. Academic year
8. Email
9. QR code placeholder

## 4. Design Principles
- Simple user interface
- Reusable components
- Equal card sizes
- Responsive layout
- Easy navigation
