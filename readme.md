
# Student Card System

## Project Description
Student Card System is a simple React application
used to display student identity cards.

## Features
- Student profile
- Student photo
- Student details
- QR code placeholder
- Student status
- Reusable components

## Technologies Used
- React.js
- JavaScript
- HTML
- CSS

## How to Run

1. Open the project in VS Code.
2. Open the terminal.
3. Run npm install.
4. Run npm run dev.

## Objective
To create student ID cards using reusable
React components.
