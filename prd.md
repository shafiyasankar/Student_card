
# Product Requirements Document (PRD)

## 1. Product Name
Student Card System

## 2. Objective
To develop a simple digital student ID card
application using React.js.

## 3. Target Users
- College students
- Teachers
- College administrators

## 4. Requirements
- Display student name.
- Display roll number.
- Display department and year.
- Display student photo.
- Display student status.
- Display multiple student cards.

## 5. Reusable Components
- Cardheader
- StudentCard
- StudentProfile
- StatusBadge
- QRCode

## 6. Expected Output
A simple dashboard showing multiple
student identity cards.
